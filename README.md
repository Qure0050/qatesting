# SauceDemo SQA Automation Framework

This repository contains the complete Quality Assurance Proof of Concept for the SauceDemo e-commerce web application, built for CST8334 Software Quality Assurance.

## Project Structure
- `/pages`: Page Object Model (POM) representations of application pages.
- `/tests`: Automated Pytest and Selenium test scripts.
- `locustfile.py`: Performance and load testing script using Locust.
- `.github/workflows/qa-pipeline.yml`: GitHub Actions CI pipeline configuration.
